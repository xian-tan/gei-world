# 多人联机联调指南

本文用于两台电脑验证多人联机（HTTP + 轮询，服务端权威）。两台电脑在同一局域网时按本文操作；不在同一局域网时先按 [Tailscale 非局域网联机指南](Tailscale非局域网联机指南.md) 组网，服务地址换成 Tailscale IP 即可。

## 1. 联调目标

1. 两台电脑能连接同一个服务。
2. 房间可创建、加入、自动开局、离开、重新连接、关闭，以及保存后恢复。
3. 轮流回合和同时回合都能完整进行。
4. 服务端权威：只能操作自己的玩家；房间状态不泄露对方身份令牌和迷雾外信息。
5. 掉线处理：普通玩家离线后会被自动跳过回合，可随时重连；房主退出关闭房间。

## 2. 准备

- 电脑 A：运行服务端，同时作为房主。
- 电脑 B：加入方。
- 两台电脑代码版本一致，并先跑一遍测试：

```bash
./.conda/bin/python -m pytest
```

电脑 A 获取局域网 IP（macOS）：

```bash
ipconfig getifaddr en0   # 无输出时试 en1
```

下文用 `<A_IP>` 表示该地址。

## 3. 启动服务端

电脑 A：

```bash
./.conda/bin/python scripts/multiplayer_http_server.py --host 0.0.0.0 --port 8000
```

服务会打印房间创建、加入、开局、关闭、超时等日志，保持终端开启。

电脑 B 验证连通：

```bash
./.conda/bin/python scripts/remote_multiplayer_demo.py --url http://<A_IP>:8000 --turn-mode simultaneous
```

看到 `✓ HTTP 远端多人流程完成` 即链路正常。

## 4. 进入对局

两台电脑启动游戏：

```bash
./.conda/bin/python -m ui        # 或 ./.conda/bin/python scripts/ui_game.py
```

电脑 A（房主）：

1. 主菜单「多人联机」→ 服务地址填 `http://<A_IP>:8000`，填写名字。
2. 选择回合模式、地图类型，可选填写房间密码。
3. 点击「创建房间」，等待大厅显示 6 位房间码，把它发给电脑 B。

电脑 B：

1. 主菜单「多人联机」→ 填同样的服务地址、自己的名字、房间码（和密码）。
2. 点击「加入房间」，直接进入对局；电脑 A 会在 1 秒内自动进入。

身份令牌由游戏自动保存在本机，重新连接时只需要服务地址、名字和房间码。

## 5. 测试用例

| 编号 | 用例 | 步骤 | 期望 |
| --- | --- | --- | --- |
| A | 单人冒烟 | 主菜单「开始新游戏」，任选设置开局，建城、生产、结束回合 | AI 正常行动，无卡死 |
| B | 同时回合 | 用「同时回合」开房，双方各自行动；A 先结束，B 再结束 | A 结束后显示等待；B 结束后进入下一回合 |
| C | 轮流回合 | 用「轮流回合」开房 | 严格轮流；非当前玩家的操作被拒绝 |
| D1 | 主动离开与重连 | B 按 `Q` 离开 → A 观察 → B 在「多人联机」点「重新连接」 | A 看到离线、自动跳过、重新连接提示；B 回到原席位 |
| D2 | 掉线超时 | B 直接关闭游戏，等待约 60 秒 | A 看到“连接超时”，B 的回合被自动跳过；B 重开游戏「重新连接」可回来 |
| D3 | 房主强制跳过 | B 掉线后 A 按 `F` | 立即跳过 B 的回合 |
| D4 | 房主退出 | A 按 `Q` 离开 | B 看到“房主已退出，房间关闭”，不能继续行动 |
| E | 保存与恢复 | A 点顶部「保存」得到恢复码；之后 A 在「多人联机」房间码处填恢复码、名字填原名，点「恢复已保存房间」；B 用原名字和新房间码「加入房间」 | 双方回到保存时的局面和各自席位 |
| F1 | 密码房 | A 设置密码开房，B 不填或填错密码加入 | 提示“房间密码错误” |
| F2 | 错误输入 | 服务地址错误 / 房间码不存在 / 本机无身份记录时点「重新连接」 | 显示明确失败原因，界面不崩溃 |

## 6. 通过标准

- 自动化测试全部通过。
- 用例 B、C 各至少完成一整轮；D1~D4、E 行为符合期望。
- 任何错误输入都不会导致界面崩溃或进入半开局状态。

## 8. 常见问题

**电脑 B 连不上？** 确认服务用 `--host 0.0.0.0` 启动、地址用的是 A 的局域网 IP 而不是 `127.0.0.1`、两台电脑在同一网络、防火墙未拦截 Python；端口被占用时换 `--port 8001`。

**对局中能否在同一台电脑开两个客户端调试？** 可以，但两个窗口要用不同的名字，重新连接时按名字区分身份。开发调试还可以设置环境变量 `GEI_WORLD_DEV=1`，主菜单会出现“本机双客户端（调试）”，多人界面会出现“调试双席位房”。

**房主退出后不能重连？** 预期行为：房主退出即关闭房间。需要中途暂停时，房主先「保存」，之后用恢复码恢复房间。

## 9. 非同局域网联机

推荐 Tailscale 虚拟局域网，见 [Tailscale 非局域网联机指南](Tailscale非局域网联机指南.md)。当前服务已有房间密码、随机身份令牌和迷雾安全的公开状态，但仍是明文 HTTP、无账号与限流，不建议直接暴露到公网。
