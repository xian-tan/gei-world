### 1.2 核心玩法概述

* 多玩家同时存在
* 每个玩家初始拥有：

  * 一名移民
  * 一定数量金币
* 玩家可：

  * 使用移民建立城市
  * 使用金币在城市中生产移民或士兵
  * 使用士兵占领地图地块或攻击敌方领土 / 城市
* 地图为六边形格子
* 领土产生金币
* 战斗为士兵数量对比制
* 存在战争迷雾（视野限制）

## 2. 技术与整体架构

### 2.1 技术栈

* 语言：Python 3.x
* 运行方式（阶段性）：

  * **第一阶段**：命令行 / 本地模拟（无UI）
  * **第二阶段（可选）**：客户端 + 服务器
* 推荐结构：

  * 逻辑与渲染解耦
  * 服务端权威状态（多人）

### 2.2 架构分层

```
GameEngine
├── MapSystem          # 地图与地块管理
├── PlayerSystem       # 玩家数据
├── UnitSystem         # 单位（移民 / 士兵）
├── CitySystem         # 城市与生产
├── EconomySystem      # 金币与收入
├── CombatSystem       # 战斗与占领
├── VisionSystem       # 视野与迷雾
├── TurnSystem         # 回合与行动点
└── NetworkSystem      # 多人通信（后期）
```

## 3. 地图系统（MapSystem）

### 3.1 地图结构

* 地图由 **六边形蜂窝格** 组成
* 推荐使用 **轴向坐标（Axial Coordinates）**

  ```
  Hex(q, r)
  ```
* 每个地块包含：

```python
Tile:
  - coord: (q, r)
  - terrain_type: LAND | OCEAN
  - owner: Player | None
  - city: City | None
  - units: List[Unit]
```

### 3.2 地形生成

* 随机生成类地球地图
* 基本规则：

  * 陆地与海洋比例可配置（如 70% 海洋）
  * 陆地尽量形成连续大陆
* 要求：

  * 地图生成函数与游戏逻辑解耦
  * 支持固定随机种子（可复现）

---

## 4. 玩家系统（PlayerSystem）

### 4.1 玩家数据结构

```python
Player:
  - id
  - name
  - gold
  - cities: List[City]
  - units: List[Unit]
  - vision_tiles: Set[Tile]
```

### 4.2 初始状态

* 每个玩家初始拥有：

  * 金币（可配置）
  * 1 名移民（单位）
* 初始移民出生在随机合法陆地地块

---

## 5. 单位系统（UnitSystem）

### 5.1 单位通用属性

```python
Unit:
  - id
  - owner: Player
  - position: Tile
  - unit_type: SETTLER | SOLDIER
  - movement_points
  - vision_range
```

### 5.2 移民（Settler）

* 功能：

  * 在所在陆地格建立城市
* 限制：

  * 建城后消失
  * 不能攻击
* 建城条件：

  * 地块为陆地
  * 地块无城市
  * 不属于敌方城市核心范围

### 5.3 士兵（Soldier）

* 属性：

  * 固定移动力（如 2 格 / 回合）
  * 固定视野
* 功能：

  * 移动
  * 占领地块
  * 攻击敌方士兵 / 城市

---

## 6. 城市系统（CitySystem）

### 6.1 城市数据结构

```python
City:
  - id
  - owner: Player
  - center_tile: Tile
  - territory_tiles: Set[Tile]
  - production_queue
```

### 6.2 城市建立规则

* 城市建立后：

  * 自动获得 **中心格 + 周围 6 格**
* 城市只能建在陆地

### 6.3 城市生产

* 城市可消耗金币生产：

  * 移民
  * 士兵
* 生产规则：

  * 单位在城市中心格生成
  * 每回合最多生产 1 个单位（可扩展）

---

## 7. 经济系统（EconomySystem）

### 7.1 金币来源

* 玩家每回合获得金币：

  ```
  金币收入 = 玩家当前领地地块数量 × 单格收益
  ```

### 7.2 金币消耗

* 建造单位
* 后期可扩展建筑、科技等

---

## 8. 领土与占领系统

### 8.1 初始领地

* 城市建立时自动占领周围 6 格

### 8.2 扩张规则

* 士兵可占领相邻地块
* 占领消耗：

  * 固定数量士兵（如 1）
* 占领条件：

  * 地块为陆地
  * 士兵移动到该地块
  * 若地块属于敌方，则触发战斗

---

## 9. 战斗系统（CombatSystem）

### 9.1 战斗触发条件

* 不同玩家士兵进入同一地块

### 9.2 战斗规则

* 对比双方士兵数量
* 数量多的一方获胜
* 失败方士兵全部移除
* 胜利方：

  * 存活士兵 = 数量差
  * 获得地块控制权

### 9.3 城市攻占

* 士兵进入敌方城市中心格：

  * 若士兵数量 ≥ 防御值 → 城市易主
  * 否则士兵全灭

---

## 10. 视野系统（VisionSystem）

### 10.1 视野规则

* 每个单位提供视野
* 玩家只能看到：

  * 自己领土
  * 单位视野范围内地块

### 10.2 战争迷雾

* 不可见地块：

  * 隐藏单位信息
  * 隐藏敌方城市状态

---

## 11. 回合系统（TurnSystem）

### 11.1 回合流程

1. 玩家收入结算
2. 单位恢复移动力
3. 玩家行动阶段
4. 战斗结算
5. 回合结束

### 11.2 行动限制

* 单位移动消耗行动点
* 超出移动力不可行动

---

## 12. 多人系统（NetworkSystem）

### 12.1 多人模式

* 支持多玩家（2 ~ N）
* 服务器维护唯一游戏状态
* 客户端仅发送指令

### 12.2 指令式交互

```json
{
  "action": "MOVE_UNIT",
  "unit_id": 12,
  "target": [q, r]
}
```

# 第二阶段：用户界面（UI）系统需求

## 16. UI 阶段目标

### 16.1 UI 阶段定位

第二阶段 UI 的目标是：

* 为玩家提供**可视化操作界面**
* 可清晰展示：

  * 六边形地图
  * 城市、单位、领土
  * 战争迷雾
* 允许玩家通过 UI 发出标准化游戏指令

> UI **不包含任何规则逻辑**，仅作为 GameEngine 的“前端”。

---

## 17. UI 技术选型要求

### 17.1 推荐技术栈（Python）

**首选方案（推荐）：**

* `pygame`

  * 成熟稳定
  * 适合 2D 网格 / 六边形地图
  * 易于控制性能与输入

**备选方案：**

* `pyglet`
* `tkinter`（仅用于极简测试，不推荐正式使用）

### 17.2 架构约束

* UI 模块 **不得直接修改游戏状态**
* UI → 发送 Action
* GameEngine → 返回新 State
* UI → 根据 State 渲染

---

## 18. UI 系统总体架构

```
UIClient
├── RenderSystem        # 地图、单位、城市渲染
├── InputSystem         # 鼠标 / 键盘输入
├── CameraSystem        # 地图缩放、平移
├── UISystem            # 面板、按钮、提示
├── FogOfWarRenderer    # 战争迷雾
└── ClientController    # UI 与 GameEngine 的桥接
```

---

## 19. 地图渲染（RenderSystem）

### 19.1 六边形地图渲染

* 使用 **点顶式六边形（Pointy-top Hex）**
* 每个地块根据状态渲染：

  * 地形（陆地 / 海洋）
  * 所属玩家颜色
  * 是否在视野中

### 19.2 地块视觉状态

| 状态      | 显示方式 |
| ------- | ---- |
| 未探索     | 完全黑  |
| 已探索但不可见 | 灰色   |
| 当前可见    | 正常颜色 |

---

## 20. 单位与城市渲染

### 20.1 单位显示

* 不同单位类型使用不同图标：

  * 移民
  * 士兵
* 同一地块多个单位：

  * 显示数量叠加
  * 或堆叠标识

### 20.2 城市显示

* 城市显示为：

  * 中心建筑图标
  * 周围领土高亮边界
* 城市 UI 信息：

  * 所属玩家
  * 当前生产内容
  * 领地规模

## 21. 视野与战争迷雾 UI

### 21.1 迷雾规则

* UI 严格依据 VisionSystem 返回的可见地块
* UI 不得显示：

  * 不可见敌军
  * 不可见敌方城市细节

### 21.2 渲染方式

* Alpha 遮罩
* 灰度处理
* 模糊效果（可选）

## 23. UI 行为 → 游戏指令映射

UI 所有操作必须转换为**标准 Action 对象**：

```python
Action:
  - player_id
  - action_type
  - params
```

### 示例

```json
{
  "action_type": "MOVE_UNIT",
  "unit_id": 15,
  "target_tile": [3, -2]
}
```

UI 不直接调用 Unit.move() / City.build() 等方法。
