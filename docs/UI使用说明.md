# UI 使用说明

## 启动

```bash
./.conda/bin/python scripts/ui_game.py
```

也可以使用带说明的演示入口：

```bash
./.conda/bin/python scripts/ui_demo.py
```

## 开始界面

- `SPACE`：新游戏
- `L`：加载默认存档 `saves/ui_save.json`
- `ESC`：退出

如果没有默认存档，界面会显示加载失败提示。

## 游戏内操作

- 左键：选择单位/城市，或移动选中单位
- 黄色边框：当前选中单位真实可达范围
- 右键：取消当前选择
- `B` / 建城按钮：选中移民后，在移民当前位置建城
- `WASD` / 方向键：平移地图
- 鼠标拖拽：平移地图
- 滚轮：缩放地图
- `ESC`：取消当前选择；无选择时退出

## 基础流程

1. 按 `SPACE` 新游戏。
2. 左键选中初始移民。
3. 黄色边框显示可移动范围。
4. 左键移动到目标地块，或直接在当前位置按 `B` / 点击“建城(B)”按钮建城。
5. 左键点击城市，打开城市面板。
6. 在城市面板生产移民或士兵。
7. 点击“结束回合”，AI 回合会自动处理。
8. 生产士兵后探索、战斗、攻城。

## 消息反馈

界面底部消息栏会显示：

- 新手提示
- 移动、建城、生产结果
- 移动失败原因
- 建城失败原因
- 金币不足原因
- 战斗与攻城结果
- 游戏结束与获胜者

## 保存和加载

- 游戏中点击“保存”会写入 `saves/ui_save.json`。
- 开始界面按 `L` 或游戏内点击“加载”会加载该固定存档。
- 加载后会清理旧局的选中单位、选中地块、城市面板和可达高亮。

## 游戏结束

游戏结束面板会显示胜者：

- `R`：重新开始全新一局
- `ESC`：退出

## 已知限制

- UI 新游戏暂不支持自定义玩家名、玩家数、地图类型和随机种子。
- 存档槽固定为 `ui_save.json`。
- AI 仍是基础策略。
- 当前地形只有陆地和海洋。
