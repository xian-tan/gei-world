# UI 使用说明

## 启动

```bash
./.conda/bin/python scripts/ui_game.py
```

也可以使用带说明的演示入口：

```bash
./.conda/bin/python scripts/ui_demo.py
```

## 开始界面

- `SPACE`：新游戏
- `L`：打开存档列表
- `ESC`：弹出退出确认

如果没有任何存档，界面会显示没有存档提示。

## 游戏内操作

- 左键：选择单位/城市、同格对象切换；点击无可选对象的空地会取消选中
- 右键：移动/攻击选中单位
- 黄色边框：当前选中单位可右键移动范围
- 橙色轮廓：结束回合前仍有移动力的单位提示
- 青色轮廓：选中城市后的城市经济范围，范围内己方领土会提供收入
- 悬停目标地块：显示到该格的虚线最短路径预览
- `B` / 建城按钮：选中移民后，在移民当前位置建城
- 选中士兵：可用滑块选择移动人数，按 `M` 设为最大数量，按 `1`-`9` 设为对应数量
- `WASD` / 方向键：平移地图
- 鼠标拖拽：平移地图
- 滚轮：缩放地图
- `ESC`：取消当前选择；无选择时弹出退出确认框

## 基础流程

1. 按 `SPACE` 新游戏。
2. 左键选中初始移民，黄色边框显示可移动范围。
3. 右键移动到目标地块，或直接在当前位置按 `B` / 点击“建城(B)”按钮建城。
5. 左键点击城市，打开城市面板。
6. 在城市面板生产移民或士兵；士兵价格为 1 金币，可用滑块选择生产数量。
7. 点击“结束回合”，AI 回合会自动处理。
8. 生产士兵后探索、战斗、攻城；同格多个士兵可用滑块、`M` 或 `1`-`9` 选择移动数量。

## 消息反馈

界面底部消息栏会显示：

- 新手提示
- 移动、建城、生产结果
- 移动失败原因
- 建城失败原因
- 金币不足原因
- 战斗与攻城结果
- 游戏结束与获胜者

## 保存和加载

- 游戏中点击“保存”会打开多个保存槽位，可选择 `slot_1` 到 `slot_5`。
- 如果槽位已有存档，再次保存会覆盖该槽位。
- 开始界面按 `L` 或游戏内点击“加载”会打开存档列表，可选择任意已有存档。
- 发布版默认存档位于用户数据目录，可用 `GEI_WORLD_SAVE_DIR` 覆盖。
- 加载后会清理旧局的选中单位、选中地块、城市面板和可达高亮。

## 游戏结束

游戏结束面板会显示胜者：

- `R`：重新开始全新一局
- `ESC`：退出

## 已知限制

- UI 新游戏暂不支持自定义玩家名、玩家数、地图类型和随机种子。
- 存档槽固定为 `ui_save.json`。
- AI 仍是基础策略。
- 当前地形只有陆地和海洋。
