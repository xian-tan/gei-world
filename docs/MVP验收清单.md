# MVP 验收清单

本文档用于验证当前版本是否达到“可试玩单机 MVP”。执行前请在项目根目录运行命令。

## 1. 环境与测试

```bash
./.conda/bin/python -m pytest
```

验收标准：

- 测试全部通过，当前基线为 `51 passed`。
- 不依赖控制台错误信息完成主要游戏流程。

## 2. 启动 UI

```bash
./.conda/bin/python scripts/ui_game.py
```

验收标准：

- 窗口正常打开。
- 开始界面显示 `SPACE 新游戏`、`L 加载游戏`、`ESC 退出`。

## 3. 新游戏

操作：

1. 在开始界面按 `SPACE`。
2. 进入默认对局：`玩家1` 对 `AI玩家`。

验收标准：

- 地图正常渲染。
- 当前玩家、金币、城市数、单位数显示正常。
- 消息栏显示新手提示和胜利目标。

## 4. 建城

操作：

1. 左键点击初始移民。
2. 查看黄色可移动范围。
3. 如需移动，左键点击黄色范围内地块。
4. 在移民所在格按 `B` 或点击“建城(B)”按钮建城。

验收标准：

- 选中移民后提示“左键移动，按 B 或点击建城按钮建城”。
- 合法建城后移民消失，城市出现。
- 非法建城时消息栏显示具体原因。

## 5. 城市生产

操作：

1. 左键点击己方城市。
2. 在城市面板点击生产移民或士兵。

验收标准：

- 选中城市后提示当前金币和生产入口。
- 金币足够时可生产单位。
- 金币不足时点击置灰按钮会显示金币不足原因。

## 6. 单位移动

操作：

1. 左键选中单位。
2. 左键点击目标地块。

验收标准：

- 黄色边框显示真实可达范围。
- 合法移动后单位位置更新。
- 不可达、移动力不足或目标越界时消息栏显示具体失败原因。

## 7. 保存与加载

操作：

1. 游戏中点击“保存”。
2. 退出或返回开始界面后按 `L`，或游戏中点击“加载”。

验收标准：

- 保存写入默认存档 `saves/ui_save.json`。
- 加载后地图、玩家、城市、单位、回合、AI 配置和视野状态恢复。
- 加载后旧的选中单位、选中地块、城市面板和可达高亮不会残留。

## 8. 战斗与攻城

操作：

1. 生产士兵，使用滑块选择生产数量。
2. 移动士兵探索地图；同格多个士兵可用滑块选择移动数量。
3. 批量移动足够士兵进入敌方单位地块或敌方城市中心。

验收标准：

- 进入敌方单位地块会触发战斗。
- 进入敌方城市中心会触发攻城。
- 消息栏显示战斗、单位被消灭、城市被占领或游戏结束信息。

## 9. 胜负与重开

操作：

1. 达成胜负条件。
2. 在游戏结束面板按 `R` 或 `ESC`。

验收标准：

- 游戏结束面板显示胜者。
- `R` 开始全新一局，不残留旧局选择状态。
- `ESC` 退出。

## 10. 当前已知限制

- UI 新游戏暂不支持自定义玩家名、玩家数、地图类型和随机种子。
- UI 存档槽固定为 `saves/ui_save.json`。
- AI 仍是基础策略，不保证高质量对战。
- 当前地形只有陆地和海洋。
- 暂无网络多人、科技树、建筑扩展和复杂单位体系。
