# 使用说明

## 项目简介

`gei-world` 是一个 Python / pygame 单机六边形回合制策略游戏原型。玩家通过移民建城、城市生产、单位移动、战斗和攻城来击败对手。

## 推荐运行环境

本项目当前使用项目本地 Conda 环境：

```bash
./.conda/bin/python
```

安装依赖：

```bash
./.conda/bin/python -m pip install -r requirements.txt
```

运行测试：

```bash
./.conda/bin/python -m pytest
```

当前测试基线：`54 passed`。

## 启动游戏

```bash
./.conda/bin/python scripts/ui_game.py
```

其他演示脚本：

```bash
./.conda/bin/python scripts/ui_demo.py
./.conda/bin/python scripts/demo.py
./.conda/bin/python scripts/interactive_game.py
./.conda/bin/python scripts/enhanced_demo.py
```

## 游戏目标

成为唯一仍拥有城市或单位的玩家。通常路径是：

1. 使用移民建立城市。
2. 使用城市生产移民和士兵。
3. 使用士兵探索、战斗和攻城。
4. 占领或消灭对手城市与单位。

## 基础规则

- 地图为六边形格子，当前地形包括陆地和海洋。
- 移民可建城，建城后移民消失。
- 城市占领周边陆地并提供金币收入。
- 城市可消耗金币生产移民或士兵；士兵价格为 1 金币，UI 中可用滑块选择生产数量。
- 士兵可占领地块、攻击敌方单位和攻城；同格多个士兵移动时可用滑块选择移动数量。
- 单位有移动力，移动范围以黄色边框显示；悬停可达目标格会显示虚线最短路径预览。
- 多格移动会沿最短路径经过中间格，士兵会占领经过的普通陆地格。
- 士兵和移民可以下海；陆地下海会清空移动力，海面移动力减半。
- 战争迷雾会隐藏未探索和不可见区域。

## 保存与加载

UI 默认使用固定存档：

```text
saves/ui_save.json
```

- 游戏内点击“保存”写入该文件。
- 开始界面按 `L` 或游戏内点击“加载”读取该文件。

## 当前限制

- UI 新游戏暂不支持自定义玩家名、玩家数、地图类型和随机种子。
- UI 存档槽固定为 `ui_save.json`。
- AI 仍是基础策略。
- 当前没有网络多人、科技树、建筑扩展和复杂单位体系。
