# 项目状态

## 当前阶段

项目已从初级半成品推进到可试玩的单机 MVP 原型。

当前重点：

- 核心规则稳定
- UI 主流程完整
- 保存/加载可继续游玩
- 新手提示和失败原因可见
- 工作区结构整理完成

## 已具备功能

- 六边形地图生成
- 陆地 / 海洋地形
- 玩家、金币和回合系统
- 移民与士兵
- 建城与领土
- 城市生产
- 陆地、下海、海面和登陆移动规则
- 战斗与攻城
- 战争迷雾与已探索区域
- 游戏结束与胜者显示
- pygame UI
- 开始菜单、加载、退出
- 游戏结束后重开
- 默认存档 `saves/ui_save.json`
- AI 自动回合
- 结构化行动结果和失败原因

## 已知限制

- UI 新游戏暂不支持自定义玩家名、玩家数、地图类型和随机种子。
- UI 存档槽固定为 `ui_save.json`。
- AI 仍是基础策略。
- 当前地形只有陆地和海洋。
- 暂无网络多人、科技树、建筑扩展和复杂单位体系。

## 下一步建议

优先做一次手工 MVP 验收，然后根据验收结果决定：

1. 修复试玩中暴露的卡点。
2. 再考虑 AI 扩张策略、地图质量或更多玩法内容。
